# Web research
1. Scrape only URLs the user supplied or that a search step returned.
2. Extract the key facts, dates, and claims — keep each claim tied to its source URL.
3. Say plainly what you could not verify; do not invent a source.
4. Return notes in markdown with a Sources section.
